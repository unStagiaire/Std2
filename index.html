1. Introduction : pourquoi les nombres complexes ?

L'équation x² + 1 = 0 n'a aucune solution réelle : un carré est toujours positif ou nul. Pourtant, de nombreuses situations (électricité, mécanique, traitement du signal) ont besoin de solutions à cette équation.

On introduit donc un nouveau nombre, noté i, tel que :

i² = −1

L'ensemble des nombres complexes, noté ℂ, prolonge l'ensemble des réels ℝ. Tout réel est un complexe, mais l'inverse est faux.

À retenir i est un nombre imaginaire pur, de carré −1. Le mot « imaginaire » ne signifie pas irréel : c'est un outil mathématique parfaitement rigoureux.
Puissances de i
i⁰ = 1 • i¹ = i • i² = −1 • i³ = −i • i⁴ = 1
Le cycle se répète tous les 4 : pour calculer iⁿ, on regarde le reste de n dans la division par 4.

2. Forme algébrique

Définition Tout nombre complexe z s'écrit de manière unique sous la forme
z = a + ib
où a et b sont des réels. a est la partie réelle (Re(z)), b est la partie imaginaire (Im(z)).
Égalité
a + ib = a' + ib' ⟺ a = a' et b = b'
Deux complexes sont égaux si et seulement si leurs parties réelles ET imaginaires sont égales.

Addition et multiplication

On calcule comme avec des expressions littérales, puis on remplace i² par −1.

Exemple 1 (2 + 3i) + (1 − 5i) = (2+1) + (3−5)i = 3 − 2i
Exemple 2 (2 + 3i)(1 − i) = 2 − 2i + 3i − 3i² = 2 + i + 3 = 5 + i
Inverse et quotient Pour z = a + ib ≠ 0 :
1/z = (a − ib) / (a² + b²)
Pour un quotient z/z', on multiplie numérateur et dénominateur par le conjugué de z'.
Exemple 3 1/(1 + i) = (1 − i)/((1+i)(1−i)) = (1 − i)/2 = ½ − ½ i
À retenir Pour rendre réel le dénominateur d'un quotient, on multiplie par le conjugué. C'est le réflexe numéro 1 des calculs dans ℂ.

3. Conjugué d'un nombre complexe

Définition Le conjugué de z = a + ib est z̄ = a − ib. On change le signe de la partie imaginaire.
Propriétés
z + z̄ = 2 Re(z)   •   z − z̄ = 2i Im(z)
z · z̄ = a² + b² = |z|²
z + z' = z̄ + z̄'   •   z · z' = z̄ · z̄'
(z / z') = z̄ / z̄'   •   z̄ = z
Exemple z = 3 − 2i. Alors z̄ = 3 + 2i et z·z̄ = 3² + (−2)² = 13.
À retenir z est réel ⟺ z̄ = z. z est imaginaire pur ⟺ z̄ = −z.

4. Module et argument

Module Le module de z = a + ib est
|z| = √(a² + b²)
C'est la distance de l'origine au point d'affixe z. |z| ≥ 0, et |z| = 0 ⟺ z = 0.
Propriétés du module
|z · z'| = |z| · |z'|   •   |z / z'| = |z| / |z'| (z' ≠ 0)
|z|² = z · z̄   •   |zⁿ| = |z|ⁿ
|z + z'| ≤ |z| + |z'|   (inégalité triangulaire)
Argument Pour z ≠ 0, l'argument de z, noté arg(z), est l'angle θ tel que :
a = |z| · cos θ   et   b = |z| · sin θ
L'argument est défini modulo 2π.
Propriétés de l'argument
arg(z · z') = arg(z) + arg(z')   [2π]
arg(z / z') = arg(z) − arg(z')   [2π]
arg(zⁿ) = n · arg(z)   [2π]
Exemple 1 z = 1 + i. |z| = √(1² + 1²) = √2. arg(z) = π/4 car cos(π/4) = sin(π/4) = √2/2.
Exemple 2 z = 1 + i√3. |z| = √(1 + 3) = 2. arg(z) = π/3 car cos(π/3) = 1/2 et sin(π/3) = √3/2.
À retenir Pour trouver un argument, on factorise par le module et on reconnaît un cosinus et un sinus remarquables. Tableau à connaître : 0, π/6, π/4, π/3, π/2, π.

5. Représentation géométrique

Dans le plan muni d'un repère orthonormé (O, u⃗, v⃗), à tout complexe z = a + ib on associe le point M(a ; b), image de z. z est l'affixe de M.

Traductions géométriques
|z − z'| = distance entre les points d'affixes z et z'
arg(z − z') = angle orienté entre l'axe des réels et le vecteur d'affixe z − z'
Exemple 1 |z − 1| = 2 : ensemble des points à distance 2 de A(1 ; 0) → cercle de centre A et de rayon 2.
Exemple 2 |z − 1| = |z + i| : points équidistants de A(1 ; 0) et B(0 ; −1) → médiatrice de [AB].
Exemple 3 Re(z) = 2 : droite verticale d'abscisse 2. Im(z) = 1 : droite horizontale d'ordonnée 1.
À retenir |z − z₀| = r → cercle de centre z₀ et de rayon r. |z − z₀| = |z − z₁| → médiatrice du segment [z₀ ; z₁].

6. Forme exponentielle

Forme trigonométrique et exponentielle Pour z ≠ 0, avec r = |z| et θ = arg(z) :
z = r(cos θ + i sin θ) = r · eiθ
Formules d'Euler
cos θ = (eiθ + e−iθ) / 2
sin θ = (eiθ − e−iθ) / (2i)
Formule de Moivre
(eiθ)ⁿ = einθ
(cos θ + i sin θ)ⁿ = cos(nθ) + i sin(nθ)
Exemple 1 1 + i = √2 · eiπ/4. Donc (1+i)⁴ = (√2)⁴ · eiπ = 4 × (−1) = −4.
Exemple 2 — Formule d'Euler eiπ = cos π + i sin π = −1. D'où l'identité d'Euler :
eiπ + 1 = 0
À retenir La forme exponentielle simplifie les produits, quotients et puissances. C'est l'outil privilégié pour les calculs avec de grands exposants.

7. Équations du second degré

Théorème Soit az² + bz + c = 0 avec a ≠ 0 et a, b, c réels. On pose Δ = b² − 4ac.
  • Si Δ > 0 : deux solutions réelles (−b ± √Δ) / (2a)
  • Si Δ = 0 : une solution réelle −b / (2a)
  • Si Δ < 0 : deux solutions complexes conjuguées (−b ± i√(−Δ)) / (2a)
Exemple 1 z² + 2z + 5 = 0. Δ = 4 − 20 = −16 = 16 i². Solutions : z = (−2 ± 4i)/2 = −1 ± 2i.
Exemple 2 z² − 4z + 13 = 0. Δ = 16 − 52 = −36. Solutions : z = (4 ± 6i)/2 = 2 ± 3i.
Propriété importante Si z₀ est solution d'une équation à coefficients réels, alors son conjugué z̄₀ est aussi solution.
À retenir Dans ℂ, toute équation du second degré admet toujours des solutions (au moins une, au plus deux distinctes).

Exercice 1 — Calculs dans ℂ
On pose z₁ = 2 + 3i et z₂ = 1 − i.
Calculer sous forme algébrique : a) z₁ + z₂   b) z₁·z₂   c) z₁/z₂   d) |z₁|.
a) z₁ + z₂ = (2 + 3i) + (1 − i) = 3 + 2i.
b) z₁·z₂ = (2 + 3i)(1 − i) = 2 − 2i + 3i − 3i² = 2 + i + 3 = 5 + i.
c) z₁/z₂ = (2 + 3i)/(1 − i) = (2 + 3i)(1 + i)/2 = (2 + 2i + 3i + 3i²)/2 = (−1 + 5i)/2 = −½ + (5/2)i.
d) |z₁| = √(2² + 3²) = √(4 + 9) = √13.
Exercice 2 — Équation du second degré
Résoudre dans ℂ : z² − 4z + 13 = 0.
Δ = (−4)² − 4×1×13 = 16 − 52 = −36.
Δ < 0, donc les solutions sont complexes conjuguées :
z = (4 ± i√36)/2 = (4 ± 6i)/2 = 2 ± 3i.
Exercice 3 — Forme exponentielle et puissance
On pose z = 1 + i√3.
1) Calculer le module et un argument de z.
2) Écrire z sous forme exponentielle.
3) En déduire z⁶.
1) |z| = √(1² + (√3)²) = √4 = 2.
cos θ = 1/2 et sin θ = √3/2, donc θ = π/3 [2π].
2) z = 2 · eiπ/3.
3) z⁶ = (2 eiπ/3)⁶ = 2⁶ · ei·6π/3 = 64 · ei2π = 64 × 1 = 64.
Exercice 4 — Géométrie
Déterminer et représenter l'ensemble des points M d'affixe z tels que |z − 1 + i| = 2.
|z − (1 − i)| = 2 : ensemble des points à distance 2 du point A d'affixe 1 − i.
C'est le cercle de centre A(1 ; −1) et de rayon 2.
